# FA Reporting Studio — UI concept

Standalone responsive design concept based on the existing administrator overview flow.

Open `index.html` in a browser. No build step or backend is required.

The prototype includes:

- Refined sidebar navigation and workspace selector
- Fund-focused reporting hero and primary report action
- Readiness metric cards
- Reporting-health checklist and recent activity
- Contextual next-best-action panel
- Responsive desktop, compact-desktop, and mobile layouts

This is intentionally isolated from the production React application so it can be reviewed before implementation.
